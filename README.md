# 雾港来电 · 午夜频率

## 安装

使用 Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8086 。可通过 PORT 环境变量修改端口。

## 组合手记

证据手记支持在一篇内收纳多段声音来源：

- 每段来源独立保存音源（含版本）、范围与观察，可单独上移/下移排序、编辑和回听；整篇末尾另写结论。
- 仅同一音源（同一版本）且范围互相重叠或相接的片段可合并，合并前展示范围与文字变化，确认后才执行；不同版本即使时间码相同也不会并为一段。
- 移除片段不会撤销已收集的正式线索；最后一段移除后，手记保留为无音源文字手记。
- 顺序与来源随存档完整导出/导入。音源失效时只禁用该段回听，其余片段与整篇内容不受影响。
- 旧版单段（单 anchor）手记在读取存档时自动迁移为可继续编辑的单段组合手记。
